# User Data Registry System

A lightweight, terminal-based Python application designed to collect user profiles and manage data storage using local files. This project demonstrates practical knowledge of file handling (I/O) and structured data persistence.

## 🚀 Features

* *Interactive CLI:* Prompts users to input personal details, hobbies, favorite media, and goals.
* *Data Persistence:* Automatically stores and appends collected records into a structured local datos.csv file without overwriting previous entries.
* *Real-time Data Reading:* Reads existing records from the database file and displays them back to the user upon execution.

## 🛠️ Tech Stack

* *Language:* Python 3
* *Modules:* csv (Built-in Python library for file handling)

## 📂 File Structure

* ejercicio2.py: The main program containing the logic for writing and reading user data.
* datos.csv: The local flat-file database where user records are securely appended.
